TALKNET - Social Dashboard Web Application
TALKNET is a modern single-page social dashboard built with React and Vite. The platform allows users to register, manage personal profiles, publish posts, engage in discussions via comments, organize photo albums, and track personal todos.

Features
Authentication & User Profiles: Complete user lifecycle including login, registration, and profile customization.
Posts & Comments: Create and interact with posts, complete with a nested comment section.
Photo Albums: Browse image albums with dedicated modal views for full pictures.
Todos Management: Create, track, and complete daily personal tasks.
State & Data Management: Clean separation of concerns using custom hooks (useFetch, useMutation, useResourceManager) and context architecture.
Tech Stack
Frontend: React, HTML5, CSS3
Build Tool: Vite
Data / Mock API: JSON Server (db.json)
State Management: React Context API & useReducer
